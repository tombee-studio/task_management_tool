Widget設定 記法ヘルプ

YAML 形式で記述します。pages にページ名とウィジェット一覧を定義します。

基本構造
pages:
  - name: <ページ名>
    widgets:
      - title: <タイトル>
        rules:
          - table: task   # または event
            filter: <フィルタ文字列>
        type: table       # または gantt
        order:
          - task
          - event
ページ名
値対象画面
project_listプロジェクト一覧
project_detailプロジェクト詳細
type（表示形式）
値内容
tableテーブル一覧表示
ganttガントチャート表示
タスクフィルタ（filter）
フィルタキー例説明
assignee=meassignee=me自分に割り当てられたタスク
status__is_donestatus__is_done=False完了フラグ（True / False）
statusstatus=1ステータス ID で絞り込み
deadline__ltedeadline__lte=2026-12-31期日が指定日以前
deadline__gtedeadline__gte=2026-01-01期日が指定日以降
tagtag=バグタグ名で絞り込み
キーワードバグ修正タイトル・説明・進捗を横断検索

複数のフィルタはスペース区切りで組み合わせられます。例：assignee=me status__is_done=False

イベントフィルタ（table: event）
フィルタキー例説明
status__is_donestatus__is_done=False完了フラグ（True / False）
設定例
pages:
  - name: project_list
    widgets:
      - title: 自分のタスク一覧
        rules:
          - table: task
            filter: "assignee=me status__is_done=False"
        type: table
        order:
          - task
  - name: project_detail
    widgets:
      - title: 未完了タスク ガント
        rules:
          - table: task
            filter: "status__is_done=False"
          - table: event
            filter: ""
        type: gantt
        order:
          - event
          - task
